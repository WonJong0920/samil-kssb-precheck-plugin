# KSSB 공시요구 카탈로그 (4대 영역 MVP)

이 문서는 Samil KSSB Precheck 스킬이 사전검토에 사용하는 **KSSB 4대 영역 MVP 공시요구 항목**을 정의한다.

> **표준 근거**: KSSB 지속가능성 공시기준 제1호(일반사항)·제2호(기후관련 공시).
> 발행: 한국지속가능성기준위원회(KSSB) / 한국회계기준원(KASB). ISSB IFRS S1·S2의 4개 축
> (거버넌스 / 전략 / 위험관리 / 지표 및 목표) 구조에 정렬한다.
>
> **확정성 주의**: 아래 항목은 4개 축 구조에 기반한 **정성적 매핑**이다. 문단 단위 조문 인용·번호는
> 공식 원문 대조 후 확정해야 하며 현재 미확정이다. Cycle 1에서는 전체 조문 세부 구현이 아니라
> 4대 영역별 사전검토 구조·판정 체계·근거 매핑 원칙·고객 질문 생성 원칙을 고정하는 것이 목적이다.

## 항목별 상세 기준 (2N-6 Phase 1 — Q1 정밀화)

각 항목의 판정 품질을 높이기 위한 상세 기준이다. 사용 원칙:

- **탐색 키워드는 recall 보조일 뿐이다.** 키워드가 없다고 미공시로 단정하지 않고(매핑 원칙 재확인 —
  확인 불가 + 질문), 키워드가 있다고 근거를 확정하지 않는다(원문 인용 확보 + 필수 요소 대조가 기준).
  문서에서 발견한 동의어·회사 고유 표현은 키워드 목록에 없어도 후보로 쓴다.
- **"근거 확인 최소 요소"는 근거 문장의 존재를 표시하기 위한 최소 기준**이며, 충족해도 준수·적합·인증·
  감사 의견을 뜻하지 않는다(판정 라벨의 의미는 `judgment_schema.md` 그대로).
- 필수 요소 충족 여부가 애매하면 **보수적으로 낮은 판정**(partial → not_verifiable 방향)을 택하고
  고객 확인 질문으로 라우팅한다.
- **요청자료 기본값**은 확인 불가·보완 필요 시 요청자료 필드의 시작점이다(`customer_question_rules.md` §6·§7).
  자료에서 확인된 맥락(조직명·제도명 등)으로 구체화해 쓴다.

### gov-01 — 이사회(감독기구)의 감독 책임
- **탐색 키워드(참고)**: 이사회, 감독기구, ESG위원회, 지속가능경영위원회, 감사위원회, 감독, 심의, 승인, 안건, 사외이사
- **근거 확인 최소 요소**: ① 감독 주체(이사회 또는 위원회의 명칭) + ② 지속가능성 관련 위험·기회에 대한
  감독 활동의 구체 서술(보고 수령·심의·승인·안건 상정 등 1개 이상)
- **partial 전형 조건**: 위원회·기구의 존재만 확인되고 지속가능성 위험·기회에 대한 감독 범위·활동이 불명확 /
  조직도·명칭만 있고 활동 서술이 없음
- **not_verifiable 조건**: 감독 주체·감독 활동에 대한 직접 근거 문장이 발견되지 않음
- **요청자료 기본값**: 이사회·위원회 규정, 이사회/위원회 안건 목록·의사록(지속가능성 안건), 위임전결 규정

### gov-02 — 경영진의 역할·책임과 보고 체계
- **탐색 키워드(참고)**: 경영진, 대표이사, CEO, 최고지속가능성책임자, CSO, 전담 조직, 협의체, 실무 조직, 보고 체계, 보고 주기
- **근거 확인 최소 요소**: ① 경영진 차원의 역할·책임 주체(직위·조직) + ② 감독기구로의 보고 경로 또는
  보고 주기 중 1개 이상의 구체 서술
- **partial 전형 조건**: 전담 조직의 존재만 확인되고 보고 체계·주기가 불명 / 역할 서술이 선언적 문장 1개뿐
- **not_verifiable 조건**: 경영진 역할·보고 체계에 대한 직접 근거 문장이 발견되지 않음
- **요청자료 기본값**: ESG 추진 조직도, 내부 보고 체계 문서, 경영진 성과평가(KPI) 반영 관련 문서

### strat-01 — 기후 관련 위험·기회의 식별 및 사업·전략 영향
- **탐색 키워드(참고)**: 기후변화, 위험, 기회, 물리적 위험, 전환 위험, 시나리오, 중대성 평가, 사업 영향, 전략, 단기, 중기, 장기
- **근거 확인 최소 요소**: ① 식별된 기후 관련 위험·기회의 구체 내용(유형·명칭) + ② 사업·전략에 미치는
  영향의 연결 서술
- **partial 전형 조건**: 위험·기회 항목의 나열만 있고 사업·전략 영향과의 연결이 없음 / 기간 구분(단·중·장기)
  이나 식별 방법이 전혀 없음(영향 서술은 있음)
- **not_verifiable 조건**: 기후 관련 위험·기회 식별에 대한 직접 근거 문장이 발견되지 않음
- **요청자료 기본값**: 기후 리스크·기회 평가 결과서, 중대성 평가 문서, 시나리오 분석 자료

### strat-02 — 기후 관련 위험·기회의 재무적 영향
- **탐색 키워드(참고)**: 재무적 영향, 재무 영향, 비용, 투자, 매출, 자산, 부채, 손익, 현금흐름, 시나리오 분석, 정량화
- **근거 확인 최소 요소**: 기후 관련 위험·기회가 재무상태·재무성과·현금흐름에 미치는 현재 또는 예상 영향의
  서술(정성 서술 가능 — 영향 경로가 식별될 것. 정량 수치가 결합되면 근거 강도가 높아짐)
- **partial 전형 조건**: "재무적 영향이 있을 수 있다" 수준의 일반 서술만 있음 / 영향 경로 없이 금액만 있음
- **not_verifiable 조건**: 재무적 영향에 대한 직접 근거 문장이 발견되지 않음
- **요청자료 기본값**: 기후 시나리오 분석의 재무 영향 산출 자료, 내부 재무 영향 평가 자료

### risk-01 — 위험의 식별·평가·관리 프로세스
- **탐색 키워드(참고)**: 리스크 관리, 위험 식별, 위험 평가, 관리 프로세스, 전사 리스크, ERM, 통합, 리스크 맵, 대응
- **근거 확인 최소 요소**: ① 지속가능성(기후) 관련 위험의 식별·평가 절차 서술 + ② 관리·대응 절차 또는
  전사 리스크 관리와의 통합 여부 중 1개 이상
- **partial 전형 조건**: "리스크를 관리하고 있다" 수준의 선언만 있고 절차 요소(주기·기준·담당)가 불명
- **not_verifiable 조건**: 프로세스에 대한 직접 근거 문장이 발견되지 않음
- **요청자료 기본값**: 리스크 관리 규정·프로세스 문서, 전사 리스크 관리(ERM) 체계 문서, 위험 평가 결과서

### metric-01 — 온실가스 Scope 1·2 배출량 (정량)
- **탐색 키워드(참고)**: Scope 1, Scope 2, 직접 배출, 간접 배출, 온실가스 배출량, tCO2eq, tCO2-eq, 배출 실적
- **근거 확인 최소 요소**: Scope 1과 Scope 2 각각(또는 합산임이 명시된) **수치 + 단위(tCO2eq 등) + 대상 기간(연도)**
- **partial 전형 조건**: 한 Scope만 수치가 있음 / 수치는 있으나 Scope 구분·기간·단위가 불명 /
  감축 활동 서술만 있고 배출량 수치가 없음
- **not_verifiable 조건**: 배출량 관련 직접 근거 문장이 발견되지 않음
- **요청자료 기본값**: 온실가스 인벤토리 산정 명세, 배출량 데이터표, 산정 경계·방법론 문서

### metric-02 — 온실가스 Scope 3 배출량 (정량)
- **탐색 키워드(참고)**: Scope 3, 기타 간접 배출, 가치사슬, 밸류체인, 카테고리, 업스트림, 다운스트림
- **근거 확인 최소 요소**: Scope 3 **수치 + 단위 + 대상 기간**(산정 카테고리 범위가 명시되면 근거 강도가 높아짐)
- **partial 전형 조건**: "Scope 3 산정을 추진 중" 등 정성 서술만 있음 / 일부 카테고리만 수치가 있음(범위 불명)
- **not_verifiable 조건**: Scope 3 관련 직접 근거 문장이 발견되지 않음
- **요청자료 기본값**: Scope 3 산정 범위(카테고리) 정의서, 카테고리별 산정 명세·데이터, (선제 구축 확인용) 데이터 수집 체계·단계별 구축 계획
- **제도 맥락(근거설명·질문·권고 문구용 — 판정 규칙 무변경)**: Scope 3는 국내 지속가능성 공시 제도에서
  **유예(경과규정) 대상으로 논의되는 항목**이다 — 유예 개념은 확정 공시기준의 경과규정으로 지지되나,
  **구체 유예 일정은 공시 로드맵 초안 단계의 내용으로 미확정**이므로 특정 연도·기간을 확정 사실처럼 쓰지 않는다
  (hedge 필수 — 예: "공시 유예가 제시되어 있어, 확정 시 세부 일정은 달라질 수 있음"). 따라서 정량 수치 부재를
  **즉시 결함·미공시로 서술하지 않고**, 카테고리 식별·산정 경계·데이터 수집 체계의 **선제 구축** 여부 확인을
  질문·권고로 유도한다. 정량요구 판정 규칙(수치 없으면 partial — 매핑 원칙)은 그대로 적용한다.

### metric-03 — 내부 탄소가격 (조건부)
- **탐색 키워드(참고)**: 내부 탄소가격, 탄소가격, internal carbon price, 톤당, 의사결정 반영, 투자 평가
- **적용 조건 확인**: 내부 탄소가격을 운영·적용한다는 서술이 자료에서 확인될 것(없으면
  "검토 범위 외 또는 적용대상 아님" — 갭으로 단정하지 않음, 적용 여부는 질문으로 확인 가능)
- **근거 확인 최소 요소(적용 확인 시)**: 가격 수준(금액) + 적용 범위(의사결정·투자 평가 등 어디에 쓰는지)
- **partial 전형 조건**: 운영 사실만 확인되고 가격·적용 범위가 불명
- **요청자료 기본값(적용 확인 시)**: 내부 탄소가격 산정·적용 기준 문서
- **제도 맥락(근거설명·질문 문구용 — 판정 규칙 무변경)**: 톤당 내부 탄소가격은 **확정 공시기준(첫 번째 세트)의
  선택공시 허용 항목**이다. 운영이 확인되지 않을 때 근거 설명·질문에 **"선택공시 항목이므로 운영 여부 확인 필요"**
  맥락을 명시하고, 미운영·미확인을 결함이나 공시 갭으로 서술하지 않는다(위 적용 조건 확인 규칙과 정합 —
  "검토 범위 외 또는 적용대상 아님" 라벨 규칙 자체는 무변경).

### metric-04 — 에너지 사용량 (정량)
- **탐색 키워드(참고)**: 에너지 사용량, 전력 사용량, 연료 사용, kWh, MWh, GWh, TJ, GJ, toe
- **근거 확인 최소 요소**: **에너지 의미 표현 + 수치 + 에너지 단위**의 결합(기존 특칙 유지 —
  온실가스 배출량 수치(tCO2eq/Scope)는 에너지 사용량의 직접 근거가 아니다)
- **partial 전형 조건**: 에너지 절감 활동 서술만 있고 사용량 수치가 없음 / 수치는 있으나 에너지 단위가 아님
- **not_verifiable 조건**: 에너지 사용량 관련 직접 근거 문장이 발견되지 않음
- **요청자료 기본값**: 에너지 사용량 데이터표(사업장·에너지원별), 에너지 관리 체계 산출 자료

### target-01 — 온실가스 감축 목표 및 진척
- **탐색 키워드(참고)**: 감축 목표, 탄소중립, 넷제로, Net Zero, 기준연도, 목표연도, 2030, 2050, 진척, 달성률, 이행
- **근거 확인 최소 요소**: ① 목표 내용(감축률·목표연도·기준연도 또는 탄소중립 선언의 구체 서술) +
  ② 목표 대비 진척·실적 비교 서술
- **partial 전형 조건**: 목표(①)만 확인되고 진척(②)이 없음 / "감축 노력 중" 수준의 서술만 있고 목표 수치·연도가 불명
- **not_verifiable 조건**: 감축 목표 관련 직접 근거 문장이 발견되지 않음
- **요청자료 기본값**: 감축 목표 수립 문서(기준연도·경계 포함), 연도별 실적·진척 관리 자료

## 매핑 원칙

- **정량요구 항목**(metric-01, metric-02, metric-04): 수치가 없으면 "일부 근거 확인, 보완 필요"로 낮춘다.
  특히 에너지 사용량(metric-04)은 **에너지 의미 표현 + 수치 + 에너지 단위**가 결합될 때만 정량 근거로 인정한다.
  온실가스 배출량(tCO2eq/Scope) 수치는 에너지 사용량의 직접 근거가 아니다.
- **조건부 항목**(metric-03): 적용 조건(내부 탄소가격 운영)이 자료에서 확인되지 않으면
  "검토 범위 외 또는 적용대상 아님"으로 두고, 갭으로 단정하지 않는다.
- 표현·동의어 차이로 근거를 놓칠 수 있으므로, **매칭 실패는 미공시 확정이 아니다.**
  확인 불가로 표시하고 고객 확인 질문으로 연결한다.

## Cycle 1 경계

- Cycle 1은 위 4대 영역 항목으로 MVP를 고정한다. KSSB 전체 조문을 세부 구현하지 않는다.
- 항목의 조문 번호·정밀 문구 확정, 산업별 세부 지표 확장은 이후 사이클의 과제다(여기서 제안하지 않는다).
- 2N-6 Phase 1의 "항목별 상세 기준"은 판정·질문 품질을 위한 실무 기준 정밀화이며, **조문 인용 확정이 아니다**
  (상단 "확정성 주의" 유지 — 조문 대조는 여전히 미확정).
