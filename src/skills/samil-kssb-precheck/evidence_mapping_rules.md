# 근거 매핑 규칙 (Evidence Mapping Rules)

이 문서는 각 판정에 붙는 **근거 앵커(evidence anchor)**의 형식과 인정 규칙을 정의한다.
목적은 모든 판정이 원문에 추적 가능하도록 하여 컨설턴트 검수를 가능하게 하는 것이다.

## 1. 근거 앵커 필드

| 필드 | 필수 | 설명 |
|---|---|---|
| source_id | 권장 | 원본 문서 식별자(보고서명 등) |
| quote | 필수(또는 위치단서) | 원문 인용문(발췌). 자료에 실제로 존재하는 문장만 사용 |
| 위치 단서 | 필수(또는 quote) | 섹션/제목 경로, 표 식별자, (제공 시) 페이지 등 |
| heading_path | 권장 | 근거가 속한 제목 경로 |
| table_id | 표인 경우 | 표 식별자 |

- **"근거 확인" 및 "일부 근거 확인" 판정에는 근거 앵커가 최소 1개 이상 필수**다. 근거 없이 "확인" 판정을 부여하지 않는다.
- "확인 불가" 판정에는 근거 앵커가 없다(대신 고객 확인 질문으로 연결).

## 2. 근거 인정 규칙

- **직접 근거만 인정한다.** 추론·업계 상식·외부 지식은 근거가 아니다.
- 표현·동의어 차이로 근거를 놓칠 수 있다. **매칭 실패는 미공시 확정이 아니다** → "확인 불가"로 표시하고 질문으로 연결.
- 근거로 쓰는 인용문은 자료에 존재하는 원문이어야 한다. **출처 없는 숫자·문장을 생성하지 않는다.**

## 3. 정량 근거 특칙

- 정량요구 항목(예: 온실가스 배출량, 에너지 사용량)은 **수치가 결합된 근거**만 정량 근거로 인정한다.
- 수치 없이 정성 서술만 있으면 "일부 근거 확인, 보완 필요"로 낮춘다.
- **에너지 사용량(metric-04)**: 에너지 의미 표현 + 수치 + 에너지 단위(kWh/MWh/TJ/GJ/toe 등)가 결합될 때만 정량 근거로 인정한다.
  온실가스 배출량 수치(tCO2eq/Scope)는 에너지 사용량의 직접 근거가 아니다.
- 정밀 매칭 특칙: 특정 지표는 앵커 표현으로 과매칭을 막는다(예: Scope 1·2 항목에 "Scope 3" 문장을 근거로 섞지 않는다).

## 4. 상충 근거 처리

- 같은 항목에서 서로 모순되는 서술(예: "미산정" ↔ 수치 존재)이 확인되면 **"상충 또는 해석 필요"**로 판정하고 사람 검수로 넘긴다.
- 상충은 자동으로 해소하지 않는다. 기준·범위·기준연도를 고객 확인 질문으로 정리한다.

## 5. 신뢰도 표현 주의

- 판정에 붙일 수 있는 신뢰도/강도 표현은 **키워드·근거 강도 기반 휴리스틱**일 뿐 통계적 신뢰도가 아니다.
- 신뢰도 표현은 사람 검수를 대체하지 않는다. 확정·보증 표현으로 쓰지 않는다.
