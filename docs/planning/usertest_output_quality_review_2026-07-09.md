## 1. 검토 방법

- **읽기 전용 추출**: PyMuPDF(`fitz`)로 PDF 전 페이지 텍스트 추출(로컬 스크래치패드, 산출물/추출물 미커밋).
- **인용 실재성·페이지 정확도 대조**: 보고서의 **개별 인용 18건**을 정규화(공백 축약 / 공백 완전제거 2단계) 후 전 페이지 검색,
  발견 페이지 index를 보고서가 주장한 `p.N`과 대조. 렌더러가 씌운 곡선따옴표(“ ”)는 제거 후 비교.
- **포맷 정합**: MD/HTML/DOCX(문단 247개 추출) 3종의 findings 내용 동일성·포맷별 문구 차이 확인.
- **내용(판정·근거·해석) 대조**: 판정이 실린 원문 페이지(p.20·28·33·34·35·88·93·95·100·118·119) 전문을 추출해
  **라벨-근거 부합·근거 선택 강도·수치 의미 정합**을 검토(§4B). 수치는 p.100 배출/에너지 표로 교차검증.
- 재판정·재계산 없음. 스키마/코드 무변경. **본 검토는 라벨을 확정/대체하지 않는다**(§4B는 검수용 보정 관찰).

## 2. 인용 실재성·페이지 정확도 결과 (핵심 강점 + 예외 1건)

- **18건 중 17건이 주장한 페이지에 실재**. 발견 페이지 = 주장 페이지(인쇄 페이지 = PDF index+1)로 **페이지 정확도 100%**.
  - 15건은 공백 축약 기준 **완전 일치(verbatim contiguous)**.
  - 2건(metric-01 직접/간접 배출량 행)은 **공백제거 기준 일치** — 원문 `tCO₂`의 아래첨자 `₂`가 추출 시 `tCO 2`(공백)로 분리된
    아티팩트 때문. 값·행 자체는 연속 원문(§4-Q4 참조).
- **→ source-bound 규율이 실데이터에서 유지됨을 실증**. 근거 없는 항목(metric-03)은 "근거 앵커 없음"으로 정직하게 비움.

### 예외 1건 — metric-02 2번째 앵커(핵심 발견, §4-Q1)

- 인용: `온실가스 E-2-2 온실가스 배출량(Scope3) - ○` (주장 p.119) — **공백제거 기준으로도 NOT-FOUND**.
- 원문 p.119 "K-ESG 가이드라인 Index" 표의 실제 셀 배열(추출 순서):
  ```
  온실가스        ← 카테고리 헤더 (E-2-1 행에 속함)
  E-2-1
  온실가스 배출량(Scope1&Scope2)
  100
  ●
  E-2-2
  온실가스 배출량(Scope3)
  -
  ○            ← 미충족 마커
  ```
- 즉 보고서 인용은 **카테고리 헤더 "온실가스"(E-2-1의 것)를 끌어와 E-2-1 행 전체를 건너뛰고 E-2-2 셀들과 이어붙인**
  **비연속(cross-cell) 재구성 문자열**이다. 개별 토큰은 모두 실재하고 페이지도 맞으며 **해석(Scope3 = 미충족·페이지 "-")도 타당**하나,
  **연속된 원문 구절이 아니다** → 엄격한 verbatim 감사(원문 Ctrl-F)에서 실패한다.

## 4. 품질 고도화 후보 (우선순위순)

### Q1 — 표 셀을 가로지른 비연속 "인용"이 verbatim 계약을 위반 (정확성·최우선)
- **현상**: §2 예외 1건. 표/색인 콘텐츠에서 LLM이 여러 셀을 이어붙여 **원문에 연속으로 존재하지 않는 인용**을 만든다.
- **왜 중요**: 제품의 핵심 약속이 "인용 = 신뢰 가능한 **연속 원문 발췌**"인데, 스티치된 표 인용은 (1) verbatim 감사에서 실패하고
  (2) 표 셀을 흐르는 문장처럼 오인시킨다. 내용 날조는 아니지만 **인용 계약(연속성) 위반**이라 정확히 이 제품이 막아야 할 실패 유형이다.
- **귀속**: **상류 findings 생성(LLM 인용 선택)** 이슈. 렌더러는 `evidence_anchors[].quote`를 그대로 통과(재판정 없음 — 정상).
- **개선안(택1/병행, 각각 별도 사이클)**:
  1. **SKILL.md 인용 선택 지침**: 표/색인 근거는 **단일 연속 셀 값**만 인용하고(예: 인용 = `온실가스 배출량(Scope3)`),
     `분류번호 E-2-2 · 페이지 "-" · 비고 ○(미충족)`는 **인용 밖(근거 설명/위치)**에 서술. 또는 표 파생 근거를 **"표 셀 요약(비연속)"으로 명시**.
  2. **validator detect-only 경고(Phase 3-B 계열 R3 후보, Node 추가·warning-only·재판정 없음)**: `quote`가 표 행으로 보이면
     (K-ESG 마커 글리프 `●◐○` 포함, 또는 `E-2-2`류 코드토큰 + `-`만 있는 셀 혼재 등 휴리스틱) →
     "표에서 셀을 가로질러 재구성된 인용일 수 있습니다; 연속 원문 여부를 사람이 확인하세요." **기존 parity fixture에 미발화** 조건 준수.

### Q2 — 수치 표 행 인용의 열/기간 헤더 부재 (가독성·검수성)
- **현상**: `직접 tCO 2 4,657 4,829 5,921 6,794 7,533`(p.100), `소비량(계) TJ 14,905 …`(p.100),
  `총 전력사용량 MWh 1,550,261 …`(p.99), `온실가스 감축량(천tCO₂eq) 800 824 849 874 901`(p.34) 등 **연도 헤더 없는 숫자 나열**.
  이 인용들은 **연속 원문으로 검증됨**(정확성 문제 아님) — 다만 인용만으로는 어느 숫자가 어느 연도인지 알 수 없다.
- **왜 중요**: 근거 설명은 "2019~2023년"이라 단정하나 인용 자체에 연도 매핑이 없어, **검수자가 열↔기간 정렬을 원문 재확인해야** 한다.
- **개선안**: Q1-② 경고(다열 숫자 행)로 **사람 확인 유도** + SKILL.md 지침에 "수치 표 인용 시 근거 설명에 **열↔연도 매핑**을 명시" 추가.
- **부수**: 아래첨자 `₂`→`tCO 2`(공백) 추출 아티팩트. 인용은 실행 추출값 그대로라 렌더러가 임의 교정 금지(source-bound). §6 한계 문구로 이미 고지됨 — 유지.

### Q3 — 내부 기계 상태 문자열이 컨설턴트 산출물에 노출 (UX 폴리시)
- **현상**: §6 금지표현 라인이 **`수행=True, 고지문 존재=True, 발견=없음`**(MD·DOCX)으로 렌더. HTML은 추가로 **영문 키 `prohibited_terms_check`** 노출.
- **원인**: `src/renderers/kssb_report_renderer.cjs`의 `_s(true)→"True"`(L67, Python `str(True)` 출력 패리티 주석) →
  HTML(L389~) · MD(L550~) · DOCX(L764~) 3곳이 `prohibited_terms_check` 불리언을 그대로 출력.
- **왜 중요**: 대문자 `True`와 영문 키는 컨설턴트 검수 초안에서 **디버그 라인처럼 읽힌다**(evidence_mapping_rules §7 "내부 도구·영문 상태 문자열 비노출"과 결이 어긋남).
- **개선안(렌더러 표현 정합, 별도 사이클)**: 같은 불리언을 **자연스러운 한국어 산문**으로 렌더
  (예: "금지 표현 점검을 수행했으며, 고지문이 포함되어 있고, 발견된 금지 표현은 없습니다."). **재판정 아님**(같은 값의 표현 변경).
  **주의**: Node↔Python **출력 패리티 규약**과 parity fixture에 걸리므로 **양쪽 렌더러 + fixture 동시 수정** 필요.

## 4B. 내용·판정·해석 측면 (C1~C5)

> **성격**: 형식/인용 실재성(§4)과 별개로, **판정 라벨이 근거에 실제로 부합하는가 / 원문에 더 적확한 근거가 있었는가 /
> 해석에 실질 결함이 있는가**를 원문(p.20·28·33·34·35·88·93·95·100·118·119) 대조로 검토했다.
> **판정 대체가 아니다**(executor는 최종 PASS/FAIL·라벨 확정을 내리지 않음). 아래는 **사람+Codex 검수를 위한 내용 보정 관찰**이다.

### C1 — target-01: "901"이 배출 *수준* vs 감축 *량*으로 혼용, 조정 없이 병치 (내용·최우선)
- 앵커1(서술 p.34): "2027년까지 온실가스 배출량을 **901천tCO₂eq으로 감축**" → 901을 목표 **배출 수준**으로 읽게 함.
- 앵커2(표 p.34): "온실가스 **감축량**(천tCO₂eq) 800 824 849 874 901" → 901은 2027년 **감축량(delta)**.
- **원문 교차검증(p.100)**: 2023년 실배출 계 ≈ **794천**tCO₂. 만약 901천이 목표 **배출 수준**이면 오히려 **증가**라 감축 목표로 성립 불가.
  → 901은 **감축량**으로 보는 것이 정합적. 즉 앵커1의 "901천으로 감축"은 **원문 자체가 느슨한 표현**이며 두 인용의 901은 의미가 다르다.
- **문제**: 보고서가 두 인용을 **의미 조정 없이 병치**하고, 이 level↔amount 모호성을 표면화하지 않음. missing_info("기준연도·산정 경계·목표 대비 실적")가 부분적으로 덮으나 **핵심 모호성 자체는 미노출**.
- **개선안**: 고객 확인 질문을 날카롭게 — "901천tCO₂eq이 **목표 배출 수준**인지 **누적 감축량**인지, 기준연도·기준배출량은 무엇인지" 명시 요청.
  (상류 findings의 근거 설명/질문 문안 강화 — SKILL.md 지침 또는 프롬프트 레벨. 라벨 "일부 근거, 보완 필요"는 유지 가능.)

### C2 — metric-02: 원문 색인이 Scope3를 "미충족"으로 명시 — "일부 근거 확인" 라벨 보정 여지 (내용)
- 원문 p.119 K-ESG Index: `E-2-2 온실가스 배출량(Scope3) · 페이지 "-" · 비고 ○(미충족)`. 정량 수치 전무.
- 보고서 라벨 = **"일부 근거 확인, 보완 필요"**. 근거는 "주제 언급 존재"(p.118 관리필요 + p.119 색인)이나 **지표 자체는 사실상 미공시**.
- **관찰**: 원문의 자기 색인이 **미충족**으로 못박은 항목에 "일부 근거 **확인**"은 다소 관대할 수 있음 → **라벨 보정 검토 대상**(판정 대체 아님).
  방향: 근거 설명에 "원문 색인상 미충족(○)·페이지 미표기"를 명시하면 라벨 뉘앙스가 정직해짐.

### C3 — strat-02: 인용한 "시나리오 분석"은 기후가 아니라 재무리스크 시나리오 (내용)
- 앵커2(p.93): "시나리오 분석을 기반으로 전사전략을 반영한 중장기 투자계획". 원문 p.93의 시나리오는 **재무관리준칙 기반 재무리스크**
  (전력료 25% 상승·발전단가 120.2원/kWh·조달금리 등)이지 **기후 시나리오가 아님**.
- **관찰**: 보고서는 이를 "기후 관련 재무적 영향"의 근거로 배치하나 원문 맥락은 재무 시나리오. 라벨("일부 근거·보완 필요")과 hedge는 타당하나
  **근거의 기후 관련성이 제시보다 느슨**. 근거 설명에 "인용된 시나리오는 재무리스크 시나리오로, 기후 시나리오 재무영향과는 구분 필요"를 더하면 정확.

### C4 — 더 적확한 근거가 원문에 있었으나 미사용 (근거 선택 강도 — 상향 여지)
- gov-01/gov-02: p.88 "ESG 경영위원회의 **제언을 기반으로 K-water ESG 중장기 추진전략을 수립**"은 **감독기구의 구체적 감독 활동** 근거로
  선택된 조각(위원회 설치·조직도)보다 강함. risk-01: p.95 "재난 **26개 유형**·경영/언론/재무 리스크 **7개 유형**으로 구분, 유형별 특화 전략,
  연 2회 모의훈련"이 선택된 조각보다 프로세스 근거로 구체적.
- **관찰**: 현재 근거도 **틀리지 않으나**(모두 실재), 조각·다이어그램 라벨 대신 **더 온전한 문장**을 고르면 검수 신뢰가 오른다.
  결함이 아니라 **근거 선택 품질의 상향 여지**(SKILL.md 인용 선택 지침 §4-Q1과 동일 계열).

### C5 — metric-01: 원문은 "직접/간접", 보고서는 Scope1/Scope2로 추론 매핑 (경미)
- 원문 p.100은 `직접 tCO2` / `간접 tCO2`로 표기. 보고서는 이를 Scope1/Scope2로 매핑(표준적·타당). 다만 **추론 매핑임을 근거 설명에 명시**하면
  (직접≈Scope1, 간접≈Scope2 — location-based) 검수자가 경계를 확인하기 쉬움. 값·단위·기간은 원문과 일치(검증됨).

### 내용 측면 종합
- 라벨은 **대체로 잘 보정·일관 hedge**(과확정 없음, 조건부 항목 정직 처리, missing_info·고객질문이 실질적으로 적확).
- 단 **C1(수치 의미 혼용)은 실질 내용 결함에 가깝고 최우선**, C2·C3는 **라벨/근거 관련성 보정 관찰**, C4·C5는 **근거 품질 상향 여지**.
- 모두 **상류 findings 생성(인용·근거설명·질문 문안)** 층의 개선이며 렌더러/스키마 무관.
