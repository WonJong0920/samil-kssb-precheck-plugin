## 2. 범용 개선 규칙 (문서 비특정)

> 규칙은 특정 항목ID가 아니라 **공시 영역/패턴** 기준으로 기술한다. K-water는 예시로만 인용한다.

### 2-Q. 인용 무결성 규칙
- **QR1 — 비연속 인용 금지**: `evidence_anchors[].quote`는 **단일 연속 원문 스팬**이어야 한다. 표/색인에서 여러 셀을 가로질러 이어붙이지 않는다.
  표 파생 근거는 셀 값 하나만 인용하고, 분류번호·페이지·마커 등은 **인용 밖(위치·근거설명)**에 서술하거나 "표 셀 요약(비연속)"으로 명시.
  *(예: `온실가스 E-2-2 온실가스 배출량(Scope3) - ○`처럼 헤더+코드+마커를 가로질러 붙인 문자열은 verbatim 감사에서 실패.)*
- **QR2 — 수치 표 인용의 매핑 명시**: 연도 헤더 없는 숫자 나열을 인용할 때 근거설명에 **열↔기간(연도)·단위 매핑**을 명시.
- **QR3 — validator detect-only 경고 후보(R3/R4)**: `quote`가 표 파생으로 보이면(마커 글리프 `●◐○` 포함 / 코드토큰(`X-N-N`)+빈셀(`-`) 혼재 / 다열 숫자행) → *"표에서 재구성된 인용일 수 있습니다; 연속 원문·열 정렬을 사람이 확인하세요."* **warning-only·additive·Node 한정·기존 parity fixture 미발화**(Phase 3-B R1/R2 패턴 계승).
- **QR4 — 추출 아티팩트 불교정**: 아래첨자 분리(`tCO₂`→`tCO 2`) 등은 실행 추출값 그대로 유지(렌더러 임의 교정 금지, source-bound). 한계 고지로 커버.

### 2-C. 내용·판정 정합 규칙
- **CR1 — 수치 의미 정합**: 동일 수치가 서로 다른 의미(예: 목표 **배출 수준** vs 누적 **감축량**, 총량 vs 원단위)로 병치되면 조정하거나 근거설명에서 구분한다. **가능하면 다른 페이지 수치로 교차검증**(예: 목표치 vs 실적치의 정합성).
- **CR2 — 근거-요구사항 관련성**: 인용 맥락이 공시요구와 다른 축이면(예: **재무리스크 시나리오 ≠ 기후 시나리오**, 전사 위험관리 ≠ 지속가능성 특정 위험) 근거설명에서 그 구분을 명시. 항목명이 과대포괄로 읽히면 실제 근거 범위로 좁혀 서술.
- **CR3 — 라벨 보정 신호**: 원문의 **자기 색인/자체 평가가 "미충족·미공시"로 명시**한 항목은 근거설명에 그 사실을 명시한다. *라벨 재판정은 하지 않되*(executor 경계), 검수자가 라벨을 보정할 수 있는 신호를 남긴다.
- **CR4 — 근거 선택 강도**: 조각·다이어그램 라벨보다 **온전한 문장**을, 정의문보다 **실제 활동·수치 서술**을 우선 인용.

### 2-A. KSSB 확정기준 정합 규칙 (모든 발행사 공통)
- **AR1 — 내부탄소가격 = 선택공시(optional)**: 확정 기준상 "톤당 내부탄소가격"은 선택 공시 항목이다. 미확인 시 "검토 범위 외/적용대상 아님"으로 단정하지 말고 **"KSSB 선택공시 항목 · 운영 여부 확인 필요"**로 프레이밍.
- **AR2 — Scope 3 = 경과규정 3년 유예(2031)**: 정량 부재는 최초공시(FY2027) 기준 **유예 범위 내**로 즉시 결함이 아니다. **"유예 기간 내 · 데이터 체계 선제 구축 권고"**로 표현.
- **AR3 — 재무영향 = Impact Pathway**: 기후 위험·기회가 **비용·투자·자산·수익·현금흐름**으로 이어지는 **영향 경로**를 **계정과목·예산·투자 데이터와 연결**하도록 질문·권고를 구성(정성 서술만으로 불충분).
- **AR4 — 거버넌스 = R&R + 승인 provenance**: **작성자·승인자·총괄책임자 R&R**과 **지속가능성 재무정보 발행 승인일·승인자 공시**를 질문에 포함. 이사회·경영진·재무·지속가능성 조직 간 연결 구조를 묻는다.
- **AR5 — 생략 시 사실·근거 기술(설계 근거)**: 확정 기준의 "중요정보 없어 생략 시 그 사실·근거 기술" 요구가 플러그인의 **미공시 단정 금지 + 부족정보/사유 기술 + 고객질문 연결** 설계를 뒷받침 → **유지**(변경 불요), 고지 문구 근거로 인용 가능.
- **AR6 — 기간 정의 표준화**: **단기(1년)·중기(1~5년)·장기(5년)**(산업 특성 시 변경 가능)에 맞춰 전략/위험 기간 구분 권고를 표준화.
- **AR7 — 온실가스 방법별 구분공시**: 배출량 근거·권고에 **산정 방법론·경계·배출계수·방법별 구분**을 포함.
- **AR8 — 시점·적용대상 컨텍스트**: 시행 FY2027(2028)·연결자산 30조원↑ 단계적 적용. 산출물이 **대상사 규모·보고연도를 확정하지 못하면 "현재 미충족이 곧 위반은 아님"** 컨텍스트를 붙이고 단정을 회피.

### 2-G. 구조·컨설팅 가치 규칙 (ChatGPT 기여 통합 — CORE / EXTENDED 계층)
**CORE (MVP 내 안전 — source-bound·미공시 단정 금지 유지):**
- **GR1 — 제도 적용성·준비도 판단 섹션(짧게)**: 산출물에 "제도 적용 시점·준비도" 짧은 판단을 추가. 대상사 규모·연도 미상 시 단정 회피 문구(AR8) 필수.
- **GR2 — 고객질문 이중 분류**: 질문을 **KSSB 4영역** + **공시 준비 축(거버넌스 R&R·Scoping·기후데이터·Impact Pathway·내부통제)**으로 이중 태깅.
- **GR3 — 준비축 질문의 provenance 규율**: 준비축 질문을 missing_info→customer_question 경로에 **additive**로 추가하되, 근거는 **"공개자료에서 확인되지 않음"** provenance만 사용(없는 근거를 발견한 것처럼 날조 금지).

**EXTENDED (선택·명확 경계 — 별도 사이클):**
- **GR4 — 준비 5대 과제 gap 요약표**: (준비과제 × 현재 공개자료 확인 × 주요 공백 × 요청자료). 컨설팅 실효성↑.
- **GR5 — 연결기준 Scoping · ICSR 심화 질문**: 공개자료 검증 밖 **"고객 질의" 성격 명시**. 판정·근거 확인 주장 금지, 준비도 컨텍스트로만.
- **경계**: G축(특히 GR1/GR4/GR5)은 report_template·SKILL 콘텐츠 변경 → **각각 별도 remediation + Codex review**. 스키마·판정 로직 무변경, 재판정 금지.

### 2-U. UX·표현 규칙
- **UR1 — 내부 상태 문자열 비노출**: `수행=True`·영문 키(`prohibited_terms_check`) 등 기계 상태를 **자연어 산문**으로. (렌더러 3포맷 + Python + parity fixture 동시 수정 필요.)
- **UR2 — 워크어라운드 나레이션 비노출**: 인코딩·재읽기·파일 처리 내부 동작을 사용자 출력에 노출하지 않음(기존 B5 §2, BOM 금지). 산출물·안내 파일은 UTF-8 간주.
- **UR3 — 경로·계정 비노출**: 로컬 절대경로·계정명 비노출(에이전트 나레이션 포함).
